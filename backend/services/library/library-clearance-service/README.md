# Library Clearance Service 📚

Verifies library blocking issues and manages clearance certificates.

## Features
- Library block verification
- Clearance certificate generation (text-based PDF stub)
- Supabase Storage integration (stub)
- Kafka event publishing (stub)

## Architecture
- Layered
- SRP + Encapsulation
- REST + Events

## Endpoint
- GET /library/clearance/{student_id}
