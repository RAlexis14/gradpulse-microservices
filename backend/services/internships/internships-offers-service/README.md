# Internships Offers Service 🧑‍💼

Microservice that lists available internship offers for students.

## Responsibilities
- List active internship offers
- Retrieve offer details by ID

## Architecture
- MVC
- Low Coupling
- MongoDB

## Endpoints
- GET /internships-offers
- GET /internships-offers/{offer_id}

## Testing
- Unit tests with pytest
- MongoDB not required for tests

## CI/CD
- Isolated GitHub Actions pipeline
